# 公开发布边界

采用全新 Git 历史，只从工作目录筛选框架，未导入原仓库历史。

设计正本唯一维护在 `docs/design/`，入口见 [设计入口](design/README.md)。本仓库不再维护私人版与公开摘编版两套设计文档；发布版与工作版保持同一口径，差异只体现为私人材料与证据不随仓库发布。

## 包含

- 维护规则、跨 Agent 入口和空白页面模板。
- Python 框架、Schema、上游适配补丁及合成测试。
- 通用架构与契约设计，保留完整设计语义：问题背景、备选方案与否决理由、契约、约束、审查结论、修复过程、历史状态与未决问题均随正文发布。方案状态和当前部署状态应分别确认；正文中的验收计数与试学结论对应原文写作时点的环境，不代表当前部署或验收完成。

## 排除

- raw 和 wiki 的全部现有文件，包括 meta、索引、日志、附件和图谱。
- 课程正文、个人学习记录、私人反馈与试学原文、真实模型响应、聊天记录和运行验收快照文件。
- 本机权限设置、凭据、数据库、运行状态、备份、缓存和外部资料副本。
- 真实响应夹具及其专属回放测试；旧父仓库部署器及其专属测试。
- 依赖私人验收目录的知识准备操作测试、历史交付验证脚本。

公开测试保留合成服务与临时工作区场景。五个只针对私人历史回放或运行快照的方法未迁移。作者交付与课程扩展集成测试依赖私人知识准备样本，Q3 历史调用限额测试依赖本机实验运行器，因此这些测试模块不随公开版发布；相应实现和上游补丁保留。没有将被排除的测试计作本仓库测试通过。

排除针对原始材料本身：课程正文、学习记录与私人反馈原文不进入仓库；设计正文中由它们产生的结论、测量口径、计数与设计影响仍随文档发布，并标明其证据未随本仓库发布、无法由本仓库独立复核。

## 防误提交

`.gitignore` 负责常规忽略，`public-files.json` 为经过审查的逐文件白名单。`tools/check_public_release.py` 核对 Git 暂存区中的全部受跟踪路径与内容；`--staged` 不只检查变更文件，避免已跟踪私人文件漏检。检查同时覆盖：

- 白名单外的路径、私人目录硬拒绝、缓存与运行文件；
- 常见凭据格式（辅助信号，需人工分类确认）；
- Markdown 标题、未闭合 frontmatter、空链接标签与占位标签；
- 链接可达性：内部链接必须落在暂存树内，目录链接须包含受跟踪文件，越界路径、本机绝对路径与非 http(s) URI 一律拒绝，项目文档锚点按固定渲染规则核对。

工作区存在但未跟踪的文件不构成发布可达性；检查只读暂存树，不访问网络，也不调用模型。

白名单不是内容审核的替代品，正则也不能识别所有隐私。新增文件或修改现有设计时，审阅正文、注释、示例、JSON 夹具和差异；不得仅因文件在 tools 或 docs 下就认定可公开。禁止从旧仓库直接推送分支、标签或使用 `--mirror`。
