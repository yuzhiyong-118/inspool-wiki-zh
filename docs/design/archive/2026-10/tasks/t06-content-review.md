# T06 独立内容审查协议

## 状态与目标

已验收；阶段 P2。将 Worker 生成与 Reviewer 判断拆为独立调用，返回带原文定位的审查发现。 实际产物与验收记录见任务总表；执行中任务不视为已完成。

## 依赖与最小上下文

- 先读工作区 `AGENTS.md` 与 [agent-development-tasks](../development-tasks.md#%E7%8B%AC%E7%AB%8B%E4%B8%8A%E4%B8%8B%E6%96%87%E4%B8%8E%E4%BA%A4%E4%BB%98%E8%A7%84%E5%88%99)，规则以 AGENTS 为准。
- 前置任务：[T04](t04-p1-pilot.md)，均须验收并交付接口摘要。
- 必读：契约、总方案第三、五、六节；AGENTS 证据与冲突规则。
- 只加载本任务必要章节、发布的契约及依赖交付摘要，无需继承全部聊天。接口缺口提交协调者，不自行修改公共契约。

## 修改范围与产物

允许修改：`tools/wiki_runtime/review/`、`tools/tests/test_content_review.py`。这些是拟定路径，当前可能尚不存在。共享初始化、注册及导航由协调者处理；任何范围移交必须先记录。

交付：Reviewer 请求/响应适配接口、中文审查提示与版本摘要；可替换假模型；通过与失败的审查样例。

不做：不管理重试、不签发可信通过凭据、不改候选；首版不绑定供应商品牌或私自调用付费服务。

## 验收条件

1. 首次审查只接收任务、固定规则、原文、原页面与候选，不接收处理者自我辩护。
2. 条件扩大、数字无出处、冲突被抹平可报告具体依据；证据不足不得以置信分数代替。
3. 模型输出畸形、超时或不可用归类为环境/审查错误，不默认通过。
4. 独立调用没有可写正式库工具；测试报告区分协议测试与实际模型质量评测。
5. 测试只使用临时库或专属夹具，不改真实 raw 正文、业务状态、AGENTS 或 ADR，不覆盖已有未提交改动。

验收命令：`-B -m unittest discover -s tools/tests -p test_content_review.py -v`；真实模型评测另列样本、版本与成本。 使用 [agent-development-tasks](../development-tasks.md#%E9%AA%8C%E6%94%B6%E4%B8%8E%E7%8A%B6%E6%80%81) 中的可用 Python 解释器；新增命令必须在交付时给出完整可复现形式。

## 交付与停止条件

返回任务 ID、契约版本和摘要、修改文件、验证命令与结果、剩余风险和接口建议；完整日志留在专属运行记录。依赖缺失、跨文件所有权冲突、契约变更或需要真实环境授权时，停止相应步骤并报告；可继续不依赖它的本任务工作。开发者不得自行将任务标为最终已验收。
