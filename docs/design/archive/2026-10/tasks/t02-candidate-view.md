# T02 候选工作区与叠加视图

## 状态与目标

已验收；阶段 P1。构造当前快照叠加候选后的只读验证视图，并记录实际读取依赖。 实际产物与验收记录见任务总表；执行中任务不视为已完成。

## 依赖与最小上下文

- 先读工作区 `AGENTS.md` 与 [agent-development-tasks](../development-tasks.md#%E7%8B%AC%E7%AB%8B%E4%B8%8A%E4%B8%8B%E6%96%87%E4%B8%8E%E4%BA%A4%E4%BB%98%E8%A7%84%E5%88%99)，规则以 AGENTS 为准。
- 前置任务：[T00](t00-contracts.md)，均须验收并交付接口摘要。
- 必读：契约发布记录；总方案第五、七、八节；health 的路径解析方式。
- 只加载本任务必要章节、发布的契约及依赖交付摘要，无需继承全部聊天。接口缺口提交协调者，不自行修改公共契约。

## 修改范围与产物

允许修改：`tools/wiki_runtime/candidate/`、`tools/tests/test_candidate_view.py`。这些是拟定路径，当前可能尚不存在。共享初始化、注册及导航由协调者处理；任何范围移交必须先记录。

交付：新增、替换、移动和显式允许删除的候选模型；快照/摘要接口；临时视图或等价文件读取接口；过期检测。

不做：不应用正式变更、不编写模型审查、不自行决定允许删除 raw。

## 验收条件

1. 验证看见候选的新页面和新链接，未修改页面仍来自同一基线；绝不通过修改正式库来模拟候选。
2. 旧目标哈希与新增目标必须不存在前提都校验；依赖被用户编辑后报告失效。
3. 兼容递归分类目录、中文和空格；重复目标、大小写碰撞、路径穿越及链接逃逸拒绝。
4. 只输出路径约束与冲突证据，不宣称同进程检查等于 OS 权限隔离。
5. 测试只使用临时库或专属夹具，不改真实 raw 正文、业务状态、AGENTS 或 ADR，不覆盖已有未提交改动。

验收命令：`-B -m unittest discover -s tools/tests -p test_candidate_view.py -v`。 使用 [agent-development-tasks](../development-tasks.md#%E9%AA%8C%E6%94%B6%E4%B8%8E%E7%8A%B6%E6%80%81) 中的可用 Python 解释器；新增命令必须在交付时给出完整可复现形式。

## 交付与停止条件

返回任务 ID、契约版本和摘要、修改文件、验证命令与结果、剩余风险和接口建议；完整日志留在专属运行记录。依赖缺失、跨文件所有权冲突、契约变更或需要真实环境授权时，停止相应步骤并报告；可继续不依赖它的本任务工作。开发者不得自行将任务标为最终已验收。

任务总表与批次见 [agent-development-tasks](../development-tasks.md)；设计依据见 [agent-maintenance-plan](../../../maintenance-plan.md)。
